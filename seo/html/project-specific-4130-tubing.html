Project Specific 4130 Tubing

Procurement of Project Specific 4130 Tubing requires exact specification of outside diameter, wall thickness, and material condition. Applicable standards determine the mechanical properties and certification requirements for this chromium-molybdenum alloy.

Project Supply Approach

A project-specific supply approach works as follows:
1. The project engineer or buyer prepares a material take-off (MTO) — a complete list of all required 4130 tube sizes with quantities
2. The MTO is submitted to the supplier as a single RFQ
3. The supplier prices and confirms availability for all line items
4. A single purchase order covers all project material
5. Delivery is consolidated (single or phased deliveries aligned with project schedule)
6. MTC documentation is provided for all items in a single project package

What the Project MTO Should Include

A complete material take-off for a 4130 project should specify:

MTO ElementDetail
OD & Wall (all sizes)Every distinct tube size in the project
Footage per sizeWith waste factor included
Cut-to-lengthIf pre-cut supply is required
ConditionNormalized, As-drawn, etc. — may vary by element
StandardASTM A519, AMS-T-6736, etc. — as applicable
MTCEN 10204 3.1 for all sizes — single project package
Delivery schedulePhased if project is staged

Frequently Asked Questions

Can different sizes within a project have different standards?

Yes — a project may specify some tube sizes to AMS-T-6736 (for primary structural elements) and others to ASTM A519 (for secondary structure). The purchase order should specify the standard for each line item clearly.
